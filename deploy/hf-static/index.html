EvidenceDesk

A support copilot that answers only from retrieved documentation, cites verbatim quotes, abstains when the evidence is missing, and can only propose a note that a human must approve. Generation runs on a fine-tuned, 4-bit Gemma 4 12B distilled from Gemma 4 26B-A4B and trained on a laptop.

Run it live

This page is a static Space, the only kind a free Hugging Face account can host, so it shows recorded runs. The interactive ZeroGPU app is in deploy/hf-space. Locally, the model runs with llama.cpp:

llama-server --hf-repo UmitVice/evidencedesk-gemma-4-12b-GGUF --hf-file evidencedesk-gemma-4-12b-Q4_0.gguf \
  --jinja -c 8192 --cache-ram 0 --port 8080
# then point EvidenceDesk at it:
GENERATION_PROVIDER=openai_compatible GENERATION_BASE_URL=http://127.0.0.1:8080/v1
