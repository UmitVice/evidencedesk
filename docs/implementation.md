# Implementation status

## Current state

EvidenceDesk is implemented as a three-route ticket investigation desk. The production baseline at `0031c480f764498c23b1d9f72c919efe11311c4e` was verified through the deployed browser and public BFF before redesign. The first-visit UI has brief demo orientation, direct sample entry, combined ticket/analysis controls, original-source inspection, explicit exact-note approval, and separate saved notes. Mobile follows analyze → inspect → decide → saved result; optional questions and technical details use native disclosures. See [UX verification and before/after screenshots](ux-improvements.md). Final deployment identifiers and release checks are recorded in the GitHub release and delivery report.

- **GitHub:** existing public [UmitVice/evidencedesk](https://github.com/UmitVice/evidencedesk) reused; CLI identity UmitVice verified; master is the default and only permanent branch, and it is production; one temporary branch at a time.
- **Production:** [web](https://evidencedesk.umitvice.com) on Netlify Free and [API health](https://api.evidencedesk.umitvice.com/health) on Render Free (Ohio), with paired server-only credentials; see [deployment](deployment.md). The former Vercel projects only redirect. The original Supabase baseline was verified through public web → BFF → API → database → real Workers AI → source validation → explicit decision → persisted note; the Neon migration is documented separately.
- **Database:** development and production now use separate Neon Free projects in the console-managed `EvidenceDesk` organization (`org-divine-wind-27513562`) owned by `umitvice@gmail.com`. Production is `evidencedesk-production` (`flat-frost-26354813`); development is `evidencedesk-dev` (`cold-mode-47834829`). Both are AWS Ohio, PostgreSQL 17.11, pgvector 0.8.0, fixed 0.25 CU, with Free idle suspension. The existing Vercel-managed Vaniras Launch organization remains unchanged.
- **Runtime:** each project has a separate restricted `evidencedesk_app` login and transaction-pooled connection. Prepared statements are disabled; TLS requires certificate and hostname verification using the pinned certifi CA bundle. Administrative credentials remain local and ignored. No schema/role/database creation, RLS bypass, corpus writes, or proposal-content updates are granted to the runtime role. Five original migration checksums and all nine application-table snapshot hashes matched during migration. See [migration evidence and rollback boundaries](neon-migration.md).
- **Corpus:** 24 real BGE chunks; model/pooling/preprocessing/version manifest verified. Identical ingestion changes zero. Known webhook vector and hybrid retrieval return the retry document first. Fixture and real embedding spaces stay separate.
- **Voice notes:** the deployed UI uses bounded 30-second microphone recording → HTTPS WAV transcription through server-only Cloudflare Whisper → editable transcript → the existing validated RAG analysis → source inspection → explicit persisted-note approval. Raw audio stays in memory for processing and browser-page playback; it is not stored in PostgreSQL. Transcription shares the durable AI quota (one request) and analysis consumes a separate request. Legacy streaming adapters are retained for local tests and fail closed in live mode without a configured provider. See `docs/voice-recording-fix.md`.
- **Workers AI:** existing scoped token works. Embedding `@cf/baai/bge-small-en-v1.5`, generation `@cf/meta/llama-3.1-8b-instruct-fast`. `support-v3` uses JSON-object mode plus an explicit schema/prompt and strict local schema/citation validation. No live-to-fixture fallback.
- **OpenAI generation:** `GENERATION_PROVIDER=openai` sends the unchanged `support-v5` prompt to GPT-6 Luna (medium reasoning, strict structured outputs, `store: false`) with Cloudflare as fallback. The dedicated OpenAI project has a $5 hard monthly limit and auto-reload off. Pilot run on 48 cases with graph expansion off: 0.816 end-to-end, schema and citations 1.000, p50 3.1 s ([report](../reports/compare-openai-gpt-6-luna-graph-false.md)). Graph expansion on was not measured with Luna.
- **Answer checks:** every live answer gets deterministic review flags shown in the workspace; `/evaluations` shows seven-day counts, and `npm run review:flags` writes flagged answers to an ignored local report. Evaluation answers are checked against labeled facts. See [answer checks](../reports/answer-checks.md).
- **Development:** local only. Use native PostgreSQL 17.11 / pgvector 0.8.6, or `scripts/local-pgserver.py` (PostgreSQL 16 + pgvector) without Docker. The former dev web and API deployments and the `evidencedesk-dev` Neon project are retired; only master deploys.
- **Supabase retirement:** the former production (`xjizbcmayuojydvwykfu`) and development (`vgeyikjybphzrrarcwaj`) databases were restored for consistent export. All records, real BGE vectors, immutable notes/proposals, and quota counters were preserved. Source resources were manually paused after verification, and restricted local backups are retained for recovery; deployed EvidenceDesk no longer depends on their inactivity lifecycle. Final release evidence is recorded in `docs/neon-migration.md`.


## Open items and handoff

State on 2026-10-30: production is complete and fully in the cloud. Web runs on Netlify, the API on Render Free (it sleeps when idle), the database on Neon Free (it suspends when idle), and generation on OpenAI GPT-6 Luna with Cloudflare Workers AI as fallback. No scheduled job, keepalive, or local process is needed, and none should be added: this is a portfolio project with no real customers, and the maintainer wants nothing running regularly from their machine. CI runs only on push and pull requests.

Nothing is required. When a new session is asked to "continue", start here and confirm with the maintainer before doing any of these optional items:

1. **Hosted smoke against the live domain.** `HOSTED_URL=https://evidencedesk.umitvice.com npx playwright test --config playwright.hosted.config.ts` now targets the current domain but has not been run since the switch. It uses two live analyses.

3. **Fine-tuned Gemma on `support-v5`.** Retraining with relation lines is the next step for the self-hosted path (`reports/release-2026-10-23.md`). This is research only and does not affect production.

## Verified evidence and limits

Baseline master CI: [34416525370](https://github.com/UmitVice/evidencedesk/actions/runs/34416525370); baseline dev CI: [34416333589](https://github.com/UmitVice/evidencedesk/actions/runs/34416333589). Both ran 43 Python/API/PostgreSQL tests and six pre-redesign browser tests. As of 2026-10-30 the suite has 116 Python/API/PostgreSQL tests and 27 local browser tests, plus a separately invoked bounded hosted smoke. Native database tests and GitHub's PostgreSQL container are distinct; local Docker was not used.

The production baseline BFF checks passed session/ticket creation, real generation, exact authorized quotations, approval of the exact note, repeated approval with one note, rejection without a note, foreign session/run/proposal rejection, tampered content rejection, stale proposals, and unsupported-question abstention. Browser checks independently confirmed live source inspection, approval, refresh persistence, and rejection. Baseline deployments: API `dpl_5413aMmkq1X3BAHZS7yPx8oQq2yT`, web `dpl_HADXaR6cs3HdnYPShg1eTnSYG9t6`.

The support-v3 full live suite at clean `b1943513cef15e6f42335fbf2642bf094c09217c` processed all 40 cases: 30 real generation attempts/completions and ten engineering-control references. Twenty-eight outputs passed schema/citation checks, two failed structured validation, and five valid outputs disagreed with the expected answer/abstention status. Retrieval n=16: Recall@5 1.0 for all methods; MRR lexical 0.703125, vector 0.921875, hybrid 0.875. Latency n=30: p50 1.15 s, p95 2.44 s. Human semantic review remains pending. The held-out results were measured after prompt tuning and were not used to tune the released prompt. The original support-v1 failures and the support-v3 smoke are preserved in `reports/history`. The full evaluation used a process-only session budget of 40 within the unchanged environment cap of 40, keeping the same durable counter identity. Public sandbox limits remain ten/session/day. No counter was reset, no provider limit was bypassed, and no paid plan was used.

The original structured provider contract failed closed during activation. A bounded diagnostic reproduced contradictory insufficient-evidence claims. The revised contract preserves all validators and uses the actual ticket question when optional input is empty. Earlier failed measurements remain in the repository.

Secret files remain ignored/untracked and server-only. Only the reviewed `.env.example` is tracked. Source deployment exclusions cover private configuration and caches. Release gates include lint/types/build, actual PostgreSQL tests, browser checks, API-contract drift, dependency audits, staged publication/history scans, and deployed functional checks.
